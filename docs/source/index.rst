SunFounder Zero 2W Starter Kit
==============================

.. image:: img/kit-cover.png
   :width: 100%
   :alt: SunFounder Raspberry Pi Zero 2 W Starter Kit

|

**Learn, Code & Create.**

Thank you for choosing the SunFounder Zero 2W Starter Kit. The kit gives you everything
you need to get a **Raspberry Pi Zero 2 W** running for the first time, and the
**Raspberry Pi Zero 2 W is included**:

* the **Raspberry Pi Zero 2 W** itself, with its 40-pin GPIO header already soldered on,
* a **32 GB microSD card** with a full-size adapter, plus a **card reader**,
* an **aluminium cooling case** that doubles as a passive heatsink,
* adapters and tools: a **Mini HDMI adapter**, a **Micro USB adapter** and a **hex key**.

There is no soldering anywhere in this kit — the whole build is a screwdriver job.
